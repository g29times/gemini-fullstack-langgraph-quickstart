    - [reflection()](cci:1://file:///e:/WorkSpace/gemini-fullstack-langgraph-quickstart/backend/src/agent/graph.py:138:0-179:5)：对现有 `web_research_result` 反思，结构化返回 [Reflection](cci:2://file:///e:/WorkSpace/gemini-fullstack-langgraph-quickstart/backend/src/agent/tools_and_schemas.py:13:0-22:5)（是否充分、知识缺口、跟进查询）。

# 本地运行指南（Windows/PowerShell）

- __准备环境__
  - 在 `backend/` 创建 `.env`，写入：
    ```powershell
    GEMINI_API_KEY="你的_Gemini_API_Key"
    ```
- __安装依赖__
  - 后端：
    ```powershell
    pip install -e backend
    ```
  - 前端：
    ```powershell
    npm install
    ```
- __启动开发服务（推荐并行两个终端）__
  - 后端（在 `backend/`）：
    ```cmd
    cd backend
    .venv\Scripts\activate
    langgraph dev
    ```
    服务默认在 `http://127.0.0.1:2024`，会同时打开 LangGraph UI。
  - 前端（在 `frontend/`）：
    ```powershell
    cd frontend
    npm run dev
    ```
    前端默认 `http://localhost:5173`。页面会通过 `http://localhost:2024` 与后端通讯。
- __CLI 快速验证__（单次问答）：
  ```powershell
  python backend/examples/cli_research.py "What are the latest trends in renewable energy?"
  ```

# Docker 运行

- __构建镜像__（项目根目录）：
  ```powershell
  docker build -t gemini-fullstack-langgraph -f Dockerfile .
  ```
- __启动 Compose__（需 `GEMINI_API_KEY`，如要接入 LangSmith 再传 `LANGSMITH_API_KEY`）：
  ```powershell
  $env:GEMINI_API_KEY="你的_Gemini_API_Key"
  $env:LANGSMITH_API_KEY="你的_LangSmith_Key"  # 可选
  docker-compose up
  ```
- 访问：
  - 前端：`http://localhost:8123/app/`
  - API：`http://localhost:8123`

## 依赖管理：本地开发 vs 团队/线上

- 本地个人开发（简洁）：
  - 仅维护 `backend/pyproject.toml`。安装命令（在项目根）：
    ```powershell
    pip install -e "backend[dev]"
    ```
  - 或在 `backend/` 下：
    ```powershell
    pip install -e ".[dev]"
    ```
- 团队协作/CI/线上（可复现与一致性）：
  - 生成锁定清单：
    ```powershell
    uv pip compile backend/pyproject.toml -o backend/requirements.lock.txt
    ```
  - 同步安装到当前环境（使其与锁定文件完全一致；会安装/升级/降级/卸载）：
    ```powershell
    uv pip sync backend/requirements.lock.txt
    ```
  - 建议将 `backend/requirements.lock.txt` 纳入版本控制，PR 审阅依赖变更。
- 已提供简单入口文件：
  - `backend/requirements.txt` 含 `-e .`，用于快速安装项目及声明依赖：
    ```powershell
    pip install -r backend/requirements.txt
    ```
